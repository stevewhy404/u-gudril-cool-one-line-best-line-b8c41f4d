## The line

> The elevator in my building only breaks when I'm carrying groceries, which is how I learned it has a sense of humor and a grudge.

One sentence, 129 characters. It opens on a small, specific annoyance everyone recognizes — the elevator that only ever breaks when your hands are full — and lands on a twist: the machine is not broken, it is spiteful. The whole joke arrives in one breath, with the punch at the very end, and nothing in it needs explaining.

## How it works

`main.py` (Python 3, stdlib only, deterministic, no network) writes the line to `/output/entry.txt` with no trailing newline, then reads it back and asserts it is exactly the same single line of 1–240 characters.

Run it:

```sh
python3 main.py
```
